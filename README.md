# USD 329 2026 Bond Website

This repository contains the editable static website for the USD 329 2026 bond project.

## Files
- `index.html` — website content; project images are embedded so the site can deploy without separate binary uploads.
- `styles.css` — visual styling.
- `site.js` — navigation, image lightbox, and tax-impact calculator.
- `model.js` — interactive Three.js WHS + CTE model.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## 3D model correction
The WHS-to-CTE connection is shown with a thin flush glazed doorway plane. The earlier separate tan connector volume was removed because it projected beyond the west/left WHS facade and appeared as an unintended beige extension.

## Publishing
This is a static site intended for GitHub Pages. In repository Settings > Pages, deploy from the `main` branch and `/ (root)`.
